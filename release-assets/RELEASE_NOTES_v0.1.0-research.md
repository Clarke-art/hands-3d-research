# v0.1.0-research — published research snapshot

The repository is Public and [v0.1.0-research](https://github.com/Clarke-art/hands-3d-research/releases/tag/v0.1.0-research) is formally published. The 18 public ZIP attachments total 7,658,061,482 bytes; exact download URLs, names, sizes and SHA256 are in [DOWNLOADS.md](DOWNLOADS.md). The original licensing/research baseline is `01cfab7263c98acb3da832a902de96f5e2c6b66f`; later main commits may correct public documentation without changing the archives.

This snapshot contains original code, six core Blender models, MIDI/fingering examples, geometry tests, a research overview, 148 research cards, historical successes and important failures. **Continuous natural dual-hand motion, real-motion alignment and penetration remain unresolved. This is not a mature automatic performance product.**
