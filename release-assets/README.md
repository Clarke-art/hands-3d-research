# Published research attachments

[v0.1.0-research](https://github.com/Clarke-art/hands-3d-research/releases/tag/v0.1.0-research) is formally published in the Public repository. Its 18 research ZIPs total 7,658,061,482 bytes and can be downloaded without authentication using [DOWNLOADS.md](DOWNLOADS.md). [R1_RELEASE_ASSETS.csv](R1_RELEASE_ASSETS.csv) supplies exact names, sizes and SHA256; all assets are below 2 GiB. No LFS is used.

R0's older 22 ZIPs are superseded and are not published assets. The 18 selected R1 archives are immutable: each contains PUBLIC_FILE_INDEX.json, source-to-public identity mappings and a version/usage note. Follow [RESTORE.md](RESTORE.md) to verify archives and restore payload paths independently. ORIGINAL_PATH_MAP.csv identifies canonical aliases and intentionally excluded files. `<HANDS_ROOT>` is a logical history root and `<USER_HOME>` is a redacted home; neither is a literal runnable source path.
