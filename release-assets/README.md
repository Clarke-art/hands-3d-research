# R1 selected research attachments

R0's 22 local ZIPs are superseded for proposed publication; they are retained untouched as local review evidence and must not be uploaded wholesale. R1 packages contain only selected, normalized public members. Every package has PUBLIC_FILE_INDEX.json, original-to-public SHA mapping and a version/usage note. R1_RELEASE_ASSETS.csv supplies package hashes and sizes; all must be less than 2 GiB.

After authorized publication, download all assets listed in R1_RELEASE_ASSETS.csv, verify archive SHA, extract payload/ under a chosen logical history root, and verify member SHA using PUBLIC_FILE_INDEX.json. ORIGINAL_PATH_MAP.csv identifies canonical aliases and intentionally excluded members. `<HANDS_ROOT>` is the logical history root, `<USER_HOME>` is a redacted home, never a literal runnable source path.

No LFS pointer is used. R0 archives are not needed for the proposed public restore. External datasets/weights need their original licenses and independent acquisition; citations and original hashes do not grant redistribution. Browser frame-by-frame/pixel-identical replay is not promised for two documented diagnostic rendering groups where encoded MP4, keyframes, vectors and sources replace intermediates.
