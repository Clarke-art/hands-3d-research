# Dataset license version binding

Checked 2026-10-29. Current upstream PianoVAM_v1 card identifies CC BY-NC 4.0; the retained historical metadata/receipt identifies CC BY-NC-SA 4.0. These are not identical. The current page also contains same-license wording, so R1 does not silently select a more permissive interpretation for historic derivatives.

Sources: https://huggingface.co/datasets/PianoVAM/PianoVAM_v1/raw/main/README.md ; historical metadata revision 1f039ab9d6128626bff708faad6472d220b50eaa and project acquisition report. Citation: Kim, Park, Bae, Kim, Kwon, Lerch, Nam, PianoVAM: A Multimodal Piano Performance Dataset, ISMIR 2025.

Sharing can be possible under the applicable noncommercial terms, attribution and adaptation obligations; this is not a blanket prohibition. The main proposed package excludes the raw/derived motion cohort until original-version and derivative scope are bound, or Human accepts a reference-only publication scope. No license is changed by this report. Research code and original analysis are separated from dataset bytes. Do not erase original receipts to remove the disagreement.
