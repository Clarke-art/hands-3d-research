# TARGET_KEY_PLANNING_DESIGN · Stage A R1

状态：已实现通用接口与唯一候选；运动质量未通过，禁止提升为合格演奏入口。最高原则 HUMAN_VISIBLE_PRODUCT_QUALITY_FIRST。

## 输入与输出

`TargetKeyPlanner(keys, anchors, hand).plan(events)` 接收现有真实88键表、批准自然静态姿态、左右手身份以及按时间排序的事件对。事件字段为 `note_id, hand, midi_note, finger, note_on, note_off`；时间使用原 MIDI tempo 积分，仅统一添加0.3秒呈现前导。每个事件保留前后事件关系，拒绝声部身份错误、琴键范围外输入、无效指号、多音或持键重叠。这里的事件对是 NOTE_ON/OFF 的无损配对表示。

输出 `key_targets`、共同掌位 `segments`、`transitions`。`locate(midi,finger,root_delta)` 给出键身份、黑白键、实际可奏区域及内缩边界、未下沉指腹点、键枢轴/轴/下沉角；`root_at(plan,t)` 给出连续共同root平移；`moving_target(target,pressure)` 跟随运动键面。运动适配输出120Hz关节角、root增量与88键角度，并加入原始起止与下沉端点的精确时刻。Action在同一60fps时钟按小数帧烘焙。

指法是给定条件，不是自动教师级指法推断。当前实际生成仅右手单音；左手只在定位接口中识别身份，不宣称左手动态或和弦已验证。

## 方法

键通过现有表按 `midi_note` 查找，身份约定 `key_index=MIDI−21`。白键前段/后段和黑键升高的真实面分别处理；内缩白键3/7毫米、黑键2/2毫米。横向以实际键中心投影到可奏区域，纵向参考冻结自然指腹的前后位置；白键优先前段。没有逐音世界坐标表，键坐标来自正式几何提取。

以自然静态指腹相对横向布局计算每个目标对应的root位移中心，为每个指号设置±18毫米的规划可达区间。按事件顺序取区间交集，交集耗尽时开启下一段；共同root取该段目标中心均值在交集内的投影。白键段root纵向−5毫米、含黑键段+6毫米，垂直−2毫米，是生成前锁定的工程策略，不能作为生理证明。换位采用五次平滑函数，边界前200毫秒至后80毫秒过渡。连续位置不等于触键可达。

关节适配局部复用原FK：每指4参数、既有局部轴与自然姿态先验，使用批准静态工程范围内的有限最小二乘；同一权重、每次最多35次评估、上一采样为唯一初值。目标随当前琴键压力改变，准备/持键/释放/恢复按事件处理。每帧都对新目标求解，未增加IK骨架、刚体引擎或新Rig；这不是手工逐音pose拟合。未引入渲染后曲目特例、逐音参数或手工修补。

## 与既有系统的关系

当前历史 `right_motion.sample_right` 每根手指只用一对固定接触/下沉端点；`phases` 只有事件权重、共享stance，没有pitch条件。历史 `phrase_common.left` 与D2/D3固定键及L1/L2绑定；本轮不扩展它。旧 `performance_core.keypoint` 的键定位/枢轴和FK可复用，但旧Musette指法表与固定root不能直接用于新曲。

新增模块全部在本独立审计目录，复用 `performance_core` 的FK/键压力/真实键表，`common` 的静态root、工程范围和skin及接触评估。冻结源blend仅打开读取，以R1场景FULL_COPY建立右手验证场景；四个原静态场景core、复制手的结构及全部键网格按保存后回读验证。音频复用已有Grand样本映射和PCM算法；原MIDI与键声runtime没有修改。

## 本候选揭示的局部架构缺口

中性指腹横向区间不是“下沉时可达域”：忽略了纵深、root高度、指腹接触及关节联动。先确定root再独立适配指节，会在普通白键压力与换位时出现饱和、悬空。应将该层局部改为有限窗口的root与关节联合接触约束，使用键面可达域约束每段root，再让过渡同时满足上一指释放与下一指接近；不要继续调DIP或逐音坐标。本轮已消耗唯一候选，不实施第二轮动作求解。

紧邻同键重奏还暴露现有 `max(old release,new attack)` 键压力的仲裁限制。NOTE_OFF与NOTE_ON同一tick时旧70毫秒释放覆盖新35毫秒起音，琴键没有回弹。需要独立设计同键重触的机械阶段与事件仲裁；不得以速度、删音或改NOTE_ON/OFF解决。本轮保持既有曲线并明确FAIL。

另一组全音下移目标仅运行同一规划函数，未生成关节数组、Action或第二候选。接口可复用已证明；跨曲目物理演奏质量尚未证明。
