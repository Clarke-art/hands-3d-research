# HUMAN_VISIBLE_CONFLICT_REVIEW_R1

Agent 正常产品视角预审；Human 判断仍待定。本轮没有创建动作候选。

检查了 0.733333、0.750000、0.766667 秒三张连续60fps帧，覆盖首轮D2下沉末段与持键。每帧均保留 TEACHING TOP、SIDE OBLIQUE、REASONABLE CLOSE 成熟相机。A复用最新候选原正常画面，B只在不保存会话将外部root恢复静态，未替换当前指关节Action。没有forensic macro、局部夸张放大或覆盖手部的调试标记。第二次D2及释放阶段由完整240Hz数据和原既有视频辅助定位，不声称另行渲染了全过程B视频。

|等级|本轮结论|
|---|---|
|GROSS_VISIBLE_PENETRATION|未确认；没有明显的大面积键体吞入手部画面。|
|SUBTLE_VISIBLE_INTERFERENCE|A比B更贴近邻键，距离变化可见；但难以仅凭所选正常视图将接近/遮挡可靠判为表面穿越。|
|GEOMETRY_ONLY_CONFLICT|E2与F♯2采用此证据等级：真实皮肤点位于键体内已确证，正常产品画面尚未确认可辨的穿入缺陷。|
|VISIBILITY_UNDETERMINED|隐蔽接触面及其他观看条件仍未穷尽；不能把“当前未确认”改写为“所有角度均不可见”。|

E2接触区在D2右邻白键，小指末节侧面。F♯2在中指与无名指之间，两个闲置指末节的侧面都存在几何交叠。仅以前一轮>3mm深度门槛会漏掉无名指的较浅交叠；这不表示原门槛的计算实现出错。

A中小指更接近D2下沉键面，B中小指重新明显离开该运动键面。B掌腕回到已批准共享静态位置，所选产品视角未见额外夸张扭腕或异常搬掌；但B的D2悬空和D3失接触使它不成为合格动态动作。当前Action中的拇指已经为动态root作过协调，因此B不等于更早的原失败Action。

全局最大竖向低于键顶深度为E2 3.083mm、F♯2 3.406mm。这些值不等于从键体退出所需的最短距离：所有命中点中该距离的最大值分别为1.449mm、1.189mm。此前F♯2最深顶点1294只有约0.0056mm侧向交叠，不能用它代表所有浅层命中点。

最终：GEOMETRY_ONLY_CONFLICT / HUMAN_PENDING。没有把工程几何穿入自动升级为明显可见产品缺陷，也没有用未见大面积缺陷取消已有BLOCKED状态。
