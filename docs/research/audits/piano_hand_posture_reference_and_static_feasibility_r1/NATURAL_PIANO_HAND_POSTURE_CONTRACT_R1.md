# NATURAL_PIANO_HAND_POSTURE_CONTRACT_R1

状态：**EVIDENCE_GROUNDED_DRAFT / NOT_TEACHER_APPROVED**。R1–R4 的来源、位置、访问与许可见 [参考清单](REAL_PIANO_REFERENCE_MANIFEST_R1.md)。以下区分真实证据、产品要求与待验证推断，不创建固定角度库。Musette 第 1–2 小节及候选指法继续 DESIGN_PROVISIONAL。

## A. NATURAL_IDLE_FINGERS

- 依据：R1 可见左手内侧各指形态不同，但有 E 的额外任务；R2 可见右手长指自然弯曲。这两张照片不能覆盖左手三指全闲置的行为。
- 产品约束：普通教学视角下，不出现三指一起僵直或一起钩爪；曲度、指间距及抬起程度须与主动指状态、共同掌部位置连贯。此项是用户质量要求，不是从 R1 推导的唯一姿势。
- rig：21 骨架允许逐指屈曲及基部展开，共同 root 可运输整手；没有已验证的被动软组织耦合模型。
- 未知：三指在本曲交替中的具体形态、相位、允许靠近哪些键，以及是否需要更多掌弓表达。不能以统一正弦或几度微摆替代观察。

## B. ACTIVE_FINGER_POSTURE

- 依据：R3 确认 D/E/F#/G/A 的五指对应；R4 支持第五指多关节保持支撑。R2 仅提供静态形态参考。
- 产品约束：检查整条指链与触点法向，不能只让末端 marker 接近目标。避免单关节折叠、反折、指腹方向明显错误；不同手指允许不同组合，不强制等角、等高。
- rig：长指 MCP/PIP/DIP、拇指 CMC/MCP/IP 可转；当前求解器只使用受限旋转子空间。皮肤 pad 与刚性 marker 并非完全相同，需看变形后的接触区域。
- 未知：本模型可接受关节域、触点面积及负荷分配；现有数值关节边界只是旧工程限制，未经人体或教师验证。

## C. SHARED_PALM_CONFIGURATION

- 依据：R1/R2 都是整只手支撑多个指位；照片不提供可移植的三维掌姿。R3 的黑键音级与实际冻结键面的高度/深度相结合，构成共同掌部规划需求。
- 产品约束：同一姿态下所有指共享一个掌部变换；主动接触、下一指准备、闲置指曲度与掌底净空同时可成立。允许演奏中的掌部迁移，不要求两个八度端点同时按下，也不为每根指独立移动手掌。
- rig：现有共同 root 已具备，不应误称旧版没有共享掌部；缺少的是有参考依据的目标姿态与跨音符规划。
- 未知：满足本任务的自然共同掌姿是否存在，掌弓自由度是否足够。未证明需改 mesh/rig。

## D. WRIST_FOLLOW_THROUGH

- 依据：R4 是支持腕部活动的文字教学；R1/R2 未给出可测侧视或连续腕部轨迹。
- 产品约束：腕高与朝向必须在普通斜视/侧视可理解，与准备、承载、释放相协调；不允许为了接触而把掌腕压入键体。练习中夸张的抬腕不得直接当作正式演奏轨迹。
- rig：共同 root 可平移/旋转，现有腕骨支持有限局部表现；没有肘、肩和完整前臂上下文，无法据此认证整条手臂人体工学。
- 未知：合适腕高区间、动作相位与方向。旧 45–85 mm root 限制不升级为人体标准，也不把已用的最低 45 mm 当作正常腕高。

## E. CONTACT_AND_CLEARANCE

- 依据：R1/R2 只显示与琴键的可见关系；R3 给音级。具体毫米数来自项目真实几何，不来自网络照片。
- 产品约束：主动 pad 位于正确的可奏面；考虑键下沉后的曲面位置、黑键高差和有限 pad 面积。掌底、腕及非主动指必须检查实际变形网格，不仅检查少数代理点。闲置指轻触不自动等于 MIDI 错音，视觉与发声状态分开审查。
- rig：可以读取变形顶点和固定 pad；现有键几何/下沉规则足以提供目标面。接触与净空必须共同验收。
- 未知：严格表面接触、边缘余量、软组织压缩与完整网格碰撞；旧 3 mm marker 容差不是人体判据，也不能排除掌部穿透。

## F. TEMPORAL_CONTINUITY

- 依据：R3 的教学顺序涉及五指旋律，R4 讨论活动腕部；本次无已观看连续视频。以下连续性属于产品/工程要求，并非本轮测得的演奏速度参数。
- 产品约束：跨音符共享准备与释放，保留解分支与接触状态；不能逐帧跳换 IK 解。速度/加速度限幅通过也不能代替自然性审核。静态姿态通过不代表完整演奏通过。
- rig：可插值骨架与 root，旧版已有限速和限加速度；尚需跨事件计划及接触状态管理。
- 未知：实际随动延迟、释放轨迹、触键速度、腕部相位及风格差异。禁止用未知量补成“标准角度/标准时长”。
