## 2. 必要复杂性与范围扩张

**确实改善可见质量的新增项：** C2局部姿态分离、教学修正的部分B01/B03改善；C1双手合成保留认可的演奏。指法搜索改善的是指序结构，静态接触恢复改善的是几何可行点；二者不能记为已改善完整演奏。[E5–E8、T5、T9]

**主要数值/基础设施进步：** C6相交计数减少、CasADi轨迹速率下降、Jacobian加速、2ms局部通过、高层时限分配。这些值得保留证据，但没有带来合格的23音、完整G4→E5或Human自然度PASS。继续投入需由下一项产品判别决定，不能由沉没成本决定。[T3、T8–T12]

任意MIDI需要的能力是：可靠事件时钟、分手与持音占用、和弦/重复/穿指指法候选、前后音手位预判、可奏键面与指腹关系、连续过渡、邻指/键安全及失败反馈。**这些功能需要上下文，不自动需要全曲非线性硬优化或全皮肤Jacobian。** 针对几何可达性极限、快速跨区、复杂换指，高级规划可能必要；现有失败没有证明具体后端是唯一方法。[T5、T11、T12；架构判断]

扩张来源可追溯：单横展修正遗漏远端曲度/黑键→局部真实skin；B02中心静态失败→root比较；窗口边界原有碰撞→全段；改指法后G4→E5新风险→静态/自然族/接触路径；离散点接不起来→毫秒级耦合与长上下文。前几次扩域有证据，长期围绕新指法的难例却使原B01/B02/B03主线失去连续产品验证。[E5、T1–T12]

**未找到“已确证权重缺陷却错误改成整手规划”的证据。** 初始记录支持姿态/路径缺口；PianoVAM第一指蹼折叠是另一问题。存在的是未隔离因果、冻结大量主动/参考状态后不断扩展求解体系的风险。不能把skin交叉直接叫蒙皮错误，也不能由一次局部失败推出需要全局重规划。[E5、E9、T1、T7]

目前CasADi/IPOPT、支持特征Jacobian及多时刻联合接触IK**不必全在日常生成主链**：C1没有这些新增后端便已有认可表现；LW修正有低成本部分收益；新后端还没有完整成功证据。保留事件驱动的稀疏联合least_squares本身有充分理由。它的稀疏数值Jacobian与R2复杂几何支持特征导数应分别评估，不能“一并去掉所有Jacobian”或“一并保留所有IK”。[E3、E4、E8、T12]

## 3. A/B/C产品路线比较

下表为历史证据支持的相对判断及待验证预测；没有跨MIDI成功率或真实稳态性能统计。

| 方面 | A 轻量动画优先 | B 复杂接触规划优先 | C 分层混合 |
|---|---|---|---|
| 自然质量 | 最接近C1已有认可；模板若全新仍未验证 | 可行目标强，尚无完整自然候选；硬包络可能排除自然姿态 | 保持C1有效协调与风格，仅难段改变；推荐，跨层衔接待验证 |
| 正确触键 | 现有pad机制＋局部指腹/键面检查可用；纯视觉不足 | 面级合同、硬约束更明确；当前连续接触仍失败 | 全路线统一事件/触键验收；简单段直接生成，难段修正 |
| 跨MIDI | 需现成指法、手位/角色扩展，不能直接复制C1 Action | 原理通用，但B2/参考族/受限控制仍有样例依赖 | 可按难度复用上游和执行层；路由判据与失败率未知 |
| 粘连/穿模 | 局部可改善；B02没有解决；必要时隔离变形原因 | 实skin约束能识别/恢复局部；未保证全路径 | 整指包络/局部真实skin先行，难例受控高级处理 |
| 效率 | 历史局部29–59秒；A2首次约349秒，尚非实时 | 历史多轮数百秒、C6 1800秒；R2导数前置阻断 | 普通段预期更省，按需离线/缓存高级结果；尚无实测 |
| 研发维护 | 相对低；不能积累音名/帧号补丁 | 高：模式、导数、非光滑分支、曲线、求解器与验证 | 中：统一合同＋简单路由；若并行堆两整套引擎会失去优势 |
| 资产复用 | 高：C1/A2/B3、事件、FK、烘焙、音频 | 也能复用Rig/FK，但需较多约束适配 | 最高潜力：保留已有主线与高级技术资产的有限接口 |
| 商业落地 | 较早得到可审完整结果，但真实性/通用性风险未闭合 | 连续求解失败、运行成本和许可依赖均增加风险 | 综合风险较低的推荐假设；必须验证简单方法能处理代表缺陷 |

建议C的日常链：MIDI事件→现成候选指法＋占用校验→阶段/手位组织→复用A2类稀疏协调及手型先验→有限局部IK/姿态路径修正→实际触键与可见穿模验收→烘焙/键/声音。高级后端仅接收**已定位、具备真实事件边界的难段**。边界或预算失败应返回可审原因，不自动扩全曲、改指法或放宽几何门限。
