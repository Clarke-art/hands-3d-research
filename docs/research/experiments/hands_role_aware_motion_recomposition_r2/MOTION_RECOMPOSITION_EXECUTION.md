## 来源、表示与输入隔离

固定来源为 C1 **R04 C5(4) → R05 D5(5)**，含 R03/R06；固定目标为 **R12 F♯5(4) → R13 G5(5)**，含 R11/R14。目标窗口 **3.8128535–4.7057100s**，与来源相差 **2.571426s**，原 MIDI、NOTE_ON/OFF、指法和琴键 Action 不变。入口残留的 R10 释放任务也按原 A2 40ms 优先级纳入，未替换主来源或目标。

本轮没有重新求解、拼接三个已验证静态姿态。使用原 `SOURCE_FEATURES.npz` 的 239 个来源采样：自然活动关节形状、事件相位、实际 skin pad 与共享根运动。

真正的键位相对表示为：

`U_source(t) = inverse(K_source(t)) × W_source(t)`

`W_target(t) = K_target(t) × U_source(t − shift)`

K 是实际运动键面内接触锚点及键旋转建立的局部坐标架，按相邻事件锚点作五次平滑混合。原 Rig 世界矩阵不再被误称为相对坐标。F♯5 的键面高度约 **15.444mm**、纵深及面内范围均进入目标坐标架，G5 使用其真实白键几何；因此不是常量世界平移。

五指姿态用 `q_source − q_RSSF` 表示。目标活动指使用来源对应相位的曲度先验，并允许局部改变全部四个工程角；准备与释放从事件及来源活动边界组织，闲置姿态从原 RSSF 与有限窗口系数生成，没有直接复制来源的缺陷闲置曲线。所有手指共用唯一共享 Rig/掌腕轨迹。

表示读回通过：世界矩阵最大误差约 **3.33×10⁻¹⁶**，关节角误差约 **3.55×10⁻¹⁵°**，pad 误差约 **3.13×10⁻¹⁴mm**。这证明表示的代数读回，不证明源或目标整手安全。

生成前仅读取目标入口/出口各一个姿态及 ±1/240s 的导数样本，共 **6 个窄边界样本**；不读取目标内部关节轨迹作为生成答案。完整目标 C1 对照轨迹在 `MOTION_CANDIDATE.npz` 保存之后才读取，写入 `TARGET_C1_POSTHOC_REFERENCE.npz`。

## 唯一策略、变量与成本

先一次 8 变量外层拟合，再对 A2 活动/释放/准备任务调用有界局部 skin 接触 IK，最后产生一条五指 Cubic Hermite 曲线。其内部导数来自 PCHIP，入口/出口采用原边界导数；共享根使用来源键位相对曲线、目标键坐标架与平滑边界连接。

| 变量 | 固定边界 |
|---|---|
| 共享腕 Y、Z 窗口增量 | ±8、±5mm |
| 第一、第二核心活动指 PIP 窗口增量 | 各 ±4° |
| 中指、食指闲置 MCP 增量 | 各 0–8° |
| 拇指闲置 CMC 增量 | 0–5° |
| 第一指释放 MCP 增量 | 0–8° |
| 条件局部 IK | 每次四个原域内关节角＋合法 inset 键面 XY，共 6 变量 |

外层没有超过 8 变量，没有开放全时刻 26 维联合求解。实际：**58 支持点，94 次局部 IK，240 个诊断采样时刻**；外层一次调用、18 nfev/154 次残差评价；每次局部最多 12 nfev，81 次正常终止、13 次到预算返回。曲度先验及相邻姿态软项并未成功保住来源自然速度，不能将记录了速度特征解释为速度验收通过。

数值执行 **85.375s / 180s**，其中外层约 **47.672s**。每个外层/局部返回值优先保存，完整候选先于门禁与报告保存；异常保存自测通过。唯一正式启动收据为 `FORMAL_GENERATION_STARTED.json`，轨迹为 `CONTINUOUS_CURVE.npz`、`MOTION_CANDIDATE.npz`；局部原始 x/XY、残差及状态保存在各 `LOCAL_RESULT_*.npz`。
