# HANDS_IDLE_INDEX_BLACK_KEY_CLEARANCE_PROTOTYPE_R1

仅在原 C1 隔离副本上，测试 `IDLE_INDEX_BLACK_KEY_CLEARANCE`。两个静态配置上限已耗尽：A 为 MCP −10°、PIP +4°、DIP +2°；B 为 MCP −16°、PIP +6°、DIP +3°，均保留原展指并裁剪在既有合法域中。静态探针显示 B 改善较多但未清障，因此只将 B 制作为时间连续的失败/部分改善证据，不追加参数搜索。

触发来自原动作 LBS/corrective 后食指真实皮肤三角面，与原 Action 驱动黑键真实几何的保守 3mm AABB 邻近关系。它不是 TIP/pad/胶囊检测，也不按目标时刻、音名或指法事件设置修复姿态。这里是局部离线 feed-forward 原型：先求威胁区间，再生成轻量动作包络；没有在线 IK 或迭代求解。

统一姿态为适度 MCP 伸展抬指，附加少量 PIP/DIP 屈曲以避免完全伸直。原 MCP 展指、手掌/root、腕、其他手指及琴键曲线保持原样。用 180ms 五次 smoothstep 进入/退出，IDLE 边界另乘同样平滑门控，PREPARE 前 40ms 归零。ACTIVE/RELEASE/PREPARE 禁止生效。局部上下文 0–1.35s、2.10–3.35s 是本轮有限实验支持域，域端同样平滑归零；不宣称已覆盖整曲。

预计副作用：MCP 接近零下限时抬升不足；皮肤前伸或指间净空改变；持续抬起可能不自然；多个五次包络取最大值的接缝只保证位置连续，速度/加速度须实际测量，不预先宣称 C2。最终动作按 240Hz 烘焙到现有三骨四元数曲线，保留所有未编辑路径与曲线范围外原始关键帧。源曲线为 LINEAR，因此还要在保存后验证接缝及亚帧插值。

验收使用实际变形网格 BVH、凸键真实网格面半空间及三角面 primal/dual 深度证书。机器失败即保留失败，正俯视媒体供 Human 对照，不将静态改善当作连续安全。
