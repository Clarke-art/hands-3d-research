# Stage 1A · AI_MULTIVIEW_QC 规范 R1

日期：2026-09-27  
状态：`AI_MULTIVIEW_QC_SPEC = READY`

## 1. 检查对象与证据等级

对象是 Anchor 与派生视角的**同一三维主体假设**。逐图正确性和跨图一致性都必须成立。记录：`P` 可接受、`C` 存疑且可局部修正、`F` 明显冲突、`NV` 仅凭现有图无法验证。`NV` 不能按 `P` 计。正交视角的透视遮挡要考虑，但不能拿遮挡解释相反的比例或姿态。

本测试没有相机外参、深度图或共同的网格；所以二维图的视觉 QC 只能否定明显错误，不能数学证明八图来自同一三维对象。需要人工按手解剖复核。

## 2. 六类检查

| 类别 | 必查点 | 关键失败例 |
| --- | --- | --- |
| A 主体身份 | 成人中性右手；同一肤色/纹理趋势；指甲形态；掌宽；短前臂截断长度与粗细；掌背和掌心结构 | 手别改变；指甲/掌宽/前臂轮廓明显重造；五指数量错误 |
| B 结构比例 | 拇指相对长度与根部；四指相对长度；指根排布；第一指蹼；掌弓；腕掌比例 | 拇指突然增大或并入掌平面；指长排序变化；掌宽或虎口形态无法对应 |
| C 姿态 | RSSF 半屈曲与约 10–15° 张开；各指 MCP/PIP/DIP 弯曲趋势；腕中立；手悬空 | 某图四指近伸直，另一图明显弯曲；腕角突变；张开度突然改变 |
| D 视角 | 正确的 DORSAL、PALMAR、RADIAL、ULNAR，以及完整阶段的 DISTAL、PROXIMAL、两张 dorsal oblique；解剖学右手；对置视角关系 | 掌背/掌心误认；桡尺侧互换；镜像左手；所称侧视图仍是斜视图 |
| E 背景光照 | 背景色、曝光、皮肤色温、阴影硬度与方向；固定大面积柔光 | 背景/曝光跳变或光源明显随相机移动；强硬阴影污染指缝 |
| F 输入适配 | 主体居中、完整且留边；边界清晰；背景干净；指间有可见间隙；无接触物/饰物/文字 | 截断指尖/腕端、粘连、多指/缺指、杂物、边界脏污 |

技术范围仅用于生成母版。二维图不能直接确认 MCP/PIP/DIP 的角度值，应使用轮廓判断，再由多视角/人工检查。不得把技术角度写成 `STANDARD_HAND` 教学结论。

## 3. 执行顺序

1. 单图硬检查：手别、五指、悬空、短前臂、背景、RSSF；Anchor 不合格则不派生。
2. 建立 Anchor 的身份指纹：各指长度排序、指甲形状、掌宽与腕宽、拇指根部/虎口、前臂锥度、弯曲趋势。
3. DORSAL ↔ PALMAR 对照：核对右手镜像关系、同样的四指长度排序、掌宽、虎口与半屈曲；不可把“掌心纹理自然”代替跨视角一致性。
4. RADIAL ↔ ULNAR 对照：必须呈相对两侧轮廓；核对拇指前后遮挡、掌弓、指尖深度序列、腕掌轴线及弯曲程度。
5. 四图合看：记录每项 `P/C/F/NV` 与可见证据。关键项 A/B/C/D 有 `F` 即停止阶段 B。
6. 仅阶段 B 通过后检查后四视角；尤其核对 DISTAL/PROXIMAL 的相对方向、五指端面和两张斜视图的侧别；再检查八图总体成像一致性。
7. 若用于正式候选，还需人工确认授权、图像规格与总量、`ViewType` 映射、完整 Pre-flight；本轮不执行入门闸门判定。

## 4. 结论门槛

| 结论 | 必要条件 |
| --- | --- |
| `PASS` | 八个强制视角齐全；A–F 无关键 `F`；跨视角身份、比例、姿态、侧别有明确可观察的自洽证据；可继续 Stage 1 正式参考路线，但仍需人工审核和独立采集闸门 |
| `CONDITIONAL_PASS` | 四视角核心身份/姿态基本自洽，只有局部可定位的 `C` 或尚未完成后四视角；下一轮修正与补图后重审，当前不得作为正式八图包 |
| `FAIL` | Anchor 反复不合格，或四视角出现明显主体比例、RSSF、手别/相机侧别冲突；或者完整八图存在不能局部修正的关键冲突。停止扩展，不得用于正式包 |

`F` 与 `NV` 的区分很重要：生成器没有给出共享三维几何的证据属于 `NV`；若可见指形或姿态互相矛盾则是 `F`。
