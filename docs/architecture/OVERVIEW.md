# Architecture and execution boundary

MIDI/score events → identity/timing/hand → fingering candidate → palm/wrist/contact plan → IK/FK → skin/collision evaluation → Blender and teaching review.

Portable entrypoints: src/midi_inspect.py and src/fingering_demo.py. The latter uses a fixed MIT PianoPlayer core subset with its original license. Optional numeric fixture checks use NumPy. Core models in models/ retain approved original SHA.

src/legacy is archival source, normalized to logical roots; do not execute its cleanup, fetch, render or solver entrypoints for installation. Historical reports and experiment cards identify actual inputs, outputs, failures and evidence scope; data locators resolve into R1 selected Release assets. Runtime ABI, dynamic/native references and full musical performance replay remain outside the portable smoke qualification.

Private operational history, reinstallable dependencies, external motion/weight cohorts and selected redundant rendering intermediates are deliberately outside the generic public package. ORIGINAL_PATH_MAP.csv records aliases and exclusions; missing excluded data must never be relabeled as complete original-engine recovery.
